# deploy/login-display

Cấu hình nginx (domain, WebSocket upgrade) để mở trình duyệt đăng nhập tài khoản từ xa. Chỉ dùng khi cần xử lý checkpoint thủ công.

## Các file

| File | Việc nó làm |
|---|---|
| `install-domain.sh` | Cài bản có domain riêng. |
| `install.sh` | Cài cấu hình nginx cho màn hình đăng nhập. |
